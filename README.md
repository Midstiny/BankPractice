# Практическая работа № 1: модульное тестирование BankAccount

Выполнено по руководству «Средства тестирования Visual Studio-2022», с. 158–170.

## Состав

- `Bank.sln` — решение для Visual Studio 2022.
- `Bank/BankAccount.cs` — исправленный учебный класс банковского счёта.
- `BankTests/BankAccountTests.cs` — три теста MSTest, включая проверку исключений.
- `report.pdf` — сопроводительная записка с титульным листом, оглавлением-ссылками и закладками.
- `evidence/` — фактические результаты запусков, журналы и сведения об SDK.

## Запуск

Требуется .NET 8 SDK. Для графического интерфейса используйте Visual Studio 2022 с поддержкой .NET 8 и установленной разработкой .NET.

```powershell
dotnet restore Bank.sln
dotnet build Bank.sln --no-restore
dotnet test Bank.sln --no-build
dotnet run --project Bank/Bank.csproj
```

В Visual Studio откройте `Bank.sln`, постройте решение и выберите **Тест → Обозреватель тестов → Запустить все**.

## Этапы

1. `01-bug.trx`: тест допустимого списания выявляет ошибку `m_balance += amount` (16,54 вместо 7,44). Ошибка в этом запуске намеренная.
2. `02-fixed.trx`: тот же тест после замены на `m_balance -= amount`.
3. `03-exceptions.trx`: два теста `Assert.ThrowsException` для отрицательной суммы и превышения остатка.
4. `04-final.trx`: три итоговых теста после рефакторинга с `try/catch`, `StringAssert.Contains`, `return` и `Assert.Fail`.

Итоговые тесты дополнительно проверяют имя параметра, недопустимое значение и неизменность баланса. Учебный тип `double` сохранён по руководству. В консольном выводе добавлено форматирование до двух знаков после запятой.

Проверки выполнены через .NET CLI; использование интерфейса Visual Studio не заявляется. Исходный PDF руководства не распространяется в составе проекта.
